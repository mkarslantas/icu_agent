# Daily Clinical Assessment

## Purpose
Perform comprehensive daily clinical assessment from structured data.

## Input
- Today's structured JSON data
- Previous 2-3 days' data for trends

## Output
Turkish markdown assessment covering:
- Overall clinical trajectory
- System-by-system evaluation
- Key concerns
- Improvement areas
- Deterioration warnings

See `prompts/reports/30-daily-report.md` for detailed report format.
